# OzonBridge - Product Crawling & Ozon Export Tool

OzonBridge is a desktop-oriented toolkit for crawling product data from multiple sources, normalizing and translating product content, mapping data into Ozon-compatible structures, and exporting files for Ozon workflows.

## Project structure

- `1688_to_ozon/`: Python backend, crawling, normalization, translation, mapping, and export logic.
- `crawldesk_pro/`: Flutter desktop frontend.
- `packaging/`: Windows packaging and installer scripts.
